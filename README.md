# MangoFusion - Premium Mango Products

![MangoFusion Screenshot](/public/readme/localhost_3000_%20(1).png)

MangoFusion is a modern e-commerce platform specializing in premium mango products, featuring a responsive design with elegant navigation and product displays.

## Features

### Navigation System
- **Responsive App Bar** with logo and menu
- **Mobile Drawer** (slides from right)
- **Desktop Menu** with animated underline effect
- **Active Route Highlighting** in custom green (#008e48)
- **Smooth Transitions** between states

### UI Components
- Material-UI integration
- Blurred glass effect on scroll
- Optimized image loading
- Responsive product grids

## Installation

```bash
# Clone repository
git clone https://github.com/your-username/mango-fusion.git

# Install dependencies
cd mango-fusion
npm install

# Run development server
npm run dev
